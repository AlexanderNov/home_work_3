Консольная утилита позволяет заархивировать указанную папку с файлами.
Пример:
archiver.py archive -sf <путь к папке, которую надо архивировать> -df <(опционально) путь к папке, в которой появится zip-файл>

В результате архивации:
- получается zip-файл с датой в имени файла
- можно увидеть количество обработанных файлов
- по умолчанию zip-файл сохраняется в той же папке, где запускается утилита, но можно указать желаемую папку

Утилита также позволяет провести анализ указанной папки с файлами.
Пример:
archiver.py analyse -sf <путь к папке, которую надо анализировать>
В результате анализа:
- выводится список папок и файлов с подсчитанным размером
